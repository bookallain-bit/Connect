# Connect — Social Network Website

A complete responsive front-end prototype for the Connect social network.

## Included
- Login / registration with localStorage demo session
- Protected pages and logout
- Home feed with stories, composer, posts and interactions
- Explore / discovery
- Reels
- Messages / chat UI
- Notifications
- Profile
- Create Post with local file preview
- Responsive desktop + mobile navigation
- Dark glass / neon visual design

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Demo
Create an account on the registration tab, then you will be redirected to Home. The session is stored in browser localStorage.

## Next production phase
Connect a real backend such as Firebase:
- Firebase Authentication
- Firestore for users/posts/comments/follows/messages
- Cloud Storage for photos/videos
- Firebase Cloud Messaging for notifications

This project intentionally keeps the current data layer front-end only.
